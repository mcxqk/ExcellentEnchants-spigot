# ExcellentEnchants Luminol 26.2 适配实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将 ExcellentEnchants 5.4.3 构建为仅支持 Luminol 26.2 build 726 的 Folia 安全插件，并通过自动化测试、静态红线扫描和真实服务端启动测试。

**架构：** 使用 Luminol 26.2 的 Paper Registry Bootstrap 取代传统 Spigot/NMS 运行路径；在 Core 内增加统一 `SchedulerUtil`，业务代码按 Entity、Region、Global 和 Async 所有权调度。周期状态拆为实体或区域自有任务，共享索引使用并发集合，热重载在 Luminol 上被明确拒绝以消除跨 Region 重载竞态。

**技术栈：** Java 25、Maven 3.9.11、Luminol API 26.2 build 726、NightCore 2.16.4、JUnit Jupiter 5.13.4、Mockito 5.18.0、PowerShell、Luminol paperclip。
